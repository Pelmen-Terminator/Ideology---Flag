# Ideology Flags

Редактор вымышленных государств: одно государство — разные названия и флаги для разных политических идеологий. Работает целиком в браузере, без сервера и регистрации. Данные хранятся в IndexedDB.

## Версия 1.1

- Убраны поля «Столица» и «Дополнительное название».
- Убраны описания идеологий и описание государственного устройства в вариантах. Старый текст описания варианта переносится в «Заметки».
- Любую идеологию, включая первые 14, можно удалить: только из библиотеки или вместе со всеми её вариантами в государствах.
- Данные старых версий мигрируют автоматически при открытии. Государства, флаги и пользовательские идеологии сохраняются.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите все файлы из архива, включая папку `.github`.
2. В Settings → Pages выберите Source: GitHub Actions (или Deploy from branch → `main` / root).
3. Сайт откроется по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

## Заметки

- JSZip и шрифт загружаются с CDN, поэтому для первого открытия и работы ZIP-экспорта нужен интернет.
- Данные привязаны к адресу сайта и браузеру. Регулярно делайте резервные копии в разделе «Резервные копии».
